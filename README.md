# Photo Calendar

사진과 자유 형식 메모를 날짜별로 기록하는 Windows 데스크톱 달력 위젯입니다.

## 다운로드 및 실행

[최신 배포본 다운로드](https://github.com/kmu9842/photoCalander/releases/latest)

`PhotoCalendar-1.4.0-Windows.exe` 하나만 다운로드하여 실행합니다. Windows x64용이며, 설치나 별도의 Node.js·DLL 파일이 필요하지 않습니다. 첫 실행에는 내부 파일을 푸는 시간이 걸릴 수 있습니다.

기본 테마는 흰색·검정·회색의 폴라로이드이며, 불투명도는 30%입니다. 폴라로이드와 아날로그 테마의 종이·프레임·요일·강조색은 모노톤입니다. 사진의 원래 색은 유지하며, 원하는 색상은 테마 커스텀에서 지정할 수 있습니다. 창 상단을 드래그하여 이동하고 가장자리와 모서리로 크기를 조절합니다.

## 사용법

- 날짜를 한 번 클릭하여 메모를 편집합니다. 달력 너비를 유지한 채 창이 옆으로 늘어나 편집창이 부드럽게 슬라이드로 열립니다. 편집창 바깥을 클릭하면 닫히고 원래 너비로 돌아옵니다.
- 메모는 여러 줄을 입력할 수 있습니다. **줄 취소선** 버튼 또는 `Ctrl+5`를 누르면 커서가 있는 줄만 취소선을 켜고 끕니다. Enter와 Shift+Enter로 나눈 줄은 각각 따로 적용됩니다.
- 날짜 편집창에서 **날짜 기본 크기**를 바꾸거나 글자를 선택하고 **선택·입력 글자** 크기를 바꿉니다. 8~48px를 1px씩 조절하며, **전체 설정**과 **날짜 기본** 버튼으로 상위 크기를 다시 따르게 할 수 있습니다.
- 사진은 파일 선택, 드래그 앤 드롭, `Ctrl+V`, 붙여넣기 버튼으로 첨부합니다. 30MB 제한 없이 긴 변 최대 1,920px의 WebP와 560px 미리보기로 자동 저장합니다. 비율·투명도를 유지하고 원본 파일은 수정하지 않습니다. 움직이는 이미지는 첫 프레임을 사용합니다.
- 날짜마다 **달력 사진 블러**를 켜거나 사진 크기를 **대·중·소**로 고릅니다. **대**는 가운데 기준으로 사진을 잘라 날짜 칸 전체를 채우고, 사진 밝기에 맞춰 글자색과 글자 뒤 배경을 자동 조절합니다. **중**은 메모 아래 기존 60% 크기를 유지합니다. **소**는 오른쪽 위 사진 아이콘 자리에 28px 썸네일을 표시하고, 마우스를 올리면 날짜 칸보다 20% 큰 미리보기가 뜹니다. 메모 시작 위치와 줄바꿈 폭은 유지합니다. 블러는 달력과 마우스 미리보기에 적용하며 편집창과 크게 보기에서는 선명한 사진을 확인할 수 있습니다.
- **사진 틀 · 위치 · 기울기**를 펼치면 사진별로 폴라로이드·우표·틀 없음을 선택합니다. 미리보기에서 사진을 끌거나 가로·세로 위치와 기울기(-30~30°)를 조절합니다. 회전한 사진도 날짜 칸 안에 머무릅니다. 대는 칸을 채운 채 사진 중심을 이동하며, 소는 첫 번째 사진을 32px 프레임 썸네일로 표시합니다. 프레임·배치를 설정하지 않은 기존 소 사진은 28px를 유지합니다. **첫 번째 사진으로** 버튼으로 대표 사진을 바꿀 수 있습니다.
- **설정 → 테마**에서 라이트·다크 외에 종이 질감과 굵은 월 제목의 **폴라로이드**, 반투명 배경과 필기체 제목의 **아날로그**를 선택합니다. 프레임을 직접 지정한 사진은 테마를 바꿔도 그 틀을 유지합니다.
- **새 테마 만들기**에서 색상, 질감과 강도, 제목 스타일, 기본 사진 틀, 모서리, 불투명도, 글꼴·크기와 선 두께를 편집하고 미리본 뒤 저장합니다. 내 테마는 최대 30개까지 저장·수정·복사·삭제할 수 있으며 전체 백업에도 포함됩니다.
- 폴라로이드·우표 프레임과 종이 질감은 Forge Seedream 5.0 Pro로 비공개 생성한 실제 이미지입니다. 이미지와 생성 기록은 [public/assets](public/assets)에 있습니다.
- 설정은 **화면 / 테마 / 달력 / 창 동작 / 데이터** 카테고리로 나뉩니다. 카테고리는 좌우 방향키로도 이동할 수 있습니다.
- 상단 팔레트 또는 설정에서 달력 전체 배경색을 바꿉니다. 날짜별 색상은 편집창 팔레트에서 따로 지정합니다.
- 설정에서 전체 글자 크기를 스피너로 8~48px 범위에서 1px씩 조절합니다(기본 13px). 날짜·요일·월 제목·메모·설정 메뉴가 함께 비례해서 바뀝니다. 배경 불투명도, 시작 요일, Windows 시작 시 실행도 변경할 수 있습니다.
- Windows에 설치된 글꼴을 선택하고 달력 선 두께를 0~6px로 조절할 수 있습니다.
- 공휴일은 Windows 국가/지역을 자동 감지하거나 국가를 직접 선택해 받습니다. [Nager.Date](https://date.nager.at)의 국가 공통 공휴일을 하루 단위로 갱신하며, 오프라인에서는 저장된 자료를 표시합니다. 주·도별 공휴일은 포함하지 않습니다.
- 설정의 엑셀 가져오기·내보내기에서 CalendarTask의 목록형(날짜/내용)과 달력형(월요일~일요일)을 지원합니다. 날짜·메모·취소선·글자색·글자 크기·날짜 배경색을 옮기며, 미리보기 후 기존 메모에 추가하거나 해당 날짜 메모만 교체할 수 있습니다. 사진과 날짜별 표시 설정은 JSON 백업을 사용합니다.
- **설정 → 데이터 → 구글 캘린더 가져오기**에서 [구글 캘린더 내보내기](https://support.google.com/calendar/answer/37111?hl=ko)로 받은 `.ics` 또는 `.zip` 파일을 선택합니다. 가져올 기간을 지정하고 미리본 뒤 적용합니다. 제목·시간·장소·설명, 종일·여러 날 일정, 반복 일정과 제외·변경·취소를 읽습니다. 시간은 Windows 시간대에 맞추고 종일 날짜는 유지합니다. 반복 일정은 선택한 기간까지만 메모로 추가되며 자동 동기화는 아닙니다. 기존 사진·날짜 설정을 유지하고 적용 전 자동 백업합니다.
- 달력형 파일의 숫자 `2026.1`처럼 1월/10월이 모호한 경우 실제 연월을 직접 선택합니다. 내보낼 때는 월을 텍스트로 저장해 이 문제를 방지합니다.
- 핀 버튼으로 바탕화면 고정을 전환합니다. X는 트레이로 숨기며, 트레이 메뉴 또는 설정에서 종료합니다.

기록과 사진은 `%APPDATA%\PhotoCalendar`에 저장됩니다. 설정에서 사진을 포함한 백업을 내보내거나 불러올 수 있습니다. 개인 기록과 사진은 저장소와 배포 파일에 포함하지 않습니다.

자세한 조작은 [사용법.txt](사용법.txt)를 참고하세요.

## 개발

Windows, Node.js 22.12 이상이 필요합니다.

```powershell
npm.cmd ci
npm.cmd run dev
```

```powershell
npm.cmd test
npm.cmd run build
npm.cmd run test:desktop
npm.cmd run test:interactions
npm.cmd run test:layout
npm.cmd run test:editor-size
npm.cmd run test:formatting
npm.cmd run test:photos
npm.cmd run test:themes
npm.cmd run test:calendar-import
npm.cmd run test:rich-text
npm.cmd run test:background
```

Electron 통합 테스트는 Windows 데스크톱 세션에서 각각 실행합니다. 테스트는 임시 데이터 폴더를 사용합니다.

## 실행 파일 만들기

실행 중인 배포본을 종료한 뒤 다음 명령을 실행합니다.

```powershell
npm.cmd run package
node scripts/test-portable.mjs
```

배포할 파일은 `release/PhotoCalendar-1.4.0-Windows.exe` 하나입니다. `win-unpacked`, 소스, 개발 의존성, 테스트 결과는 함께 배포할 필요가 없습니다.

DesktopCal의 날짜별 기록 방식을 참고한 독립 앱이며, DesktopCal 계정 연동이나 클라우드 동기화는 포함하지 않습니다.
