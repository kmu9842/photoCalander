Photo Calendar — Windows 바탕화면 달력 위젯

실행
  PhotoCalendar-1.4.0-Windows.exe를 실행하세요.
  설치 없이 사용할 수 있습니다. 첫 실행에는 압축을 푸느라 잠시 걸립니다.
  실행 파일을 한 곳에 보관한 다음 사용하세요.

기본 사용
  위쪽 제목 영역을 드래그하면 위젯을 옮길 수 있습니다.
  모서리나 가장자리를 드래그하면 크기를 조절할 수 있습니다. 오른쪽 아래에 조절 손잡이가 있습니다.
  날짜를 한 번 클릭하거나, 선택한 날짜에서 Enter를 누르면 편집창이 열립니다.
  달력 너비는 그대로 유지하고 창이 옆으로 늘어나 편집창이 부드럽게 슬라이드로 들어갑니다. 닫으면 원래 너비로 돌아옵니다.
  다른 날짜 칸을 포함한 편집창 바깥을 클릭하면 닫힙니다. 해당 클릭으로 다른 편집창을 열지 않습니다.
  메모는 하나의 텍스트 영역에 입력합니다. Enter는 줄바꿈이며 여러 줄을 그대로 붙여넣을 수 있습니다.
  줄 취소선 버튼 또는 Ctrl+5를 누르면 커서가 있는 줄만 취소선을 켜고 끕니다.
  Enter나 Shift+Enter로 나눈 다른 줄에는 적용되지 않습니다.
  날짜 기본 크기는 해당 날짜 메모의 기본 크기입니다. 글자를 선택하고 선택·입력 글자 크기를 바꾸면 그 글자만 바뀝니다.
  선택한 글자가 없으면 이후 입력할 글자 크기를 지정합니다. 크기는 8~48px, 1px 단위입니다.
  전체 설정 버튼은 날짜 기본 크기를, 날짜 기본 버튼은 선택한 글자 크기를 각각 상위 설정으로 되돌립니다.
  취소선은 편집창과 달력에서 실제 선으로 표시됩니다. Ctrl+Z로 실행을 취소할 수 있습니다.
  사진은 날짜 칸에 끌어 놓거나 사진 추가 버튼으로 첨부합니다.
  사진 추가 버튼은 Windows 파일 탐색기를 엽니다.
  편집창의 사진 영역에도 파일을 끌어 놓을 수 있습니다.
  붙여넣기 버튼과 Ctrl+V를 모두 지원합니다.
  색상 버튼을 누르면 팔레트가 펼쳐집니다. 48색과 직접 색상 지정을 지원합니다.
  날짜를 선택한 상태에서 Ctrl+V로 클립보드 사진도 붙여 넣을 수 있습니다.
  하루 최대 20장의 JPG/PNG/WEBP/GIF를 지원하며, 30MB 파일 크기 제한은 없습니다.
  새 사진은 긴 변 최대 1,920px의 WebP와 560px 미리보기로 자동 축소 저장합니다.
  원본 비율과 투명도는 유지하고 선택한 원본 파일은 수정하지 않습니다.
  움직이는 GIF/WEBP는 첫 프레임을 저장하며, 손상되거나 디코더가 처리할 수 없는 이미지는 오류로 안내합니다.
  사진을 클릭하면 크게 볼 수 있습니다. 좌우 화살표로 다음 사진을 봅니다.
  날짜 편집창의 달력 사진 블러를 켜면 해당 날짜의 달력 미리보기가 흐려집니다.
  편집창의 사진과 크게 보기에서는 선명한 원본을 확인할 수 있습니다.
  대: 사진 가운데를 기준으로 잘라 날짜 칸 전체를 채웁니다. 글자는 사진 위에 표시하며 밝기에 맞춰 색상과 글자 뒤 배경을 자동 조절합니다.
  중: 메모 아래에 기존 60% 높이로 사진 전체를 표시합니다.
  소: 오른쪽 위 사진 아이콘 자리에 28px 썸네일을 표시합니다. 마우스를 올리면 날짜 칸보다 20% 큰 미리보기가 뜹니다.
  소 썸네일을 클릭하면 크게 보기가 열립니다. 키보드로 썸네일에 초점을 옮겨도 미리보기를 볼 수 있습니다.
  사진 크기를 바꿔도 메모 시작 위치와 줄바꿈 폭은 유지합니다. 소 사진은 메모 공간을 차지하지 않습니다.
  블러는 마우스 미리보기에도 적용합니다. 편집창과 크게 보기에서는 사진 전체를 선명하게 확인합니다.
  메모와 사진은 자동 저장됩니다. 저장 실패 시에만 재시도 버튼이 표시됩니다.

위젯 설정
  화면: 배경색, 불투명도, 글자 크기, 글꼴, 선 두께
  테마: 라이트, 다크, 폴라로이드, 아날로그와 내 테마 디자인·저장
  달력: 시작 요일, 공휴일 표시와 국가
  창 동작: 표시 위치, Windows 시작 시 실행, 앱 종료
  데이터: 구글 캘린더, 엑셀, 전체 백업과 복원
  위쪽 카테고리 버튼으로 전환합니다. 좌우 방향키와 Home/End도 사용할 수 있습니다.
  핀: 바탕화면 고정 / 일반 위젯 전환
  설정 > 표시 위치: 바탕화면 고정, 일반 위젯, 항상 위에
  바탕화면 고정은 Windows Explorer 바탕화면에 붙이는 방식입니다.
  환경에 따라 고정할 수 없을 때는 일반 위젯 모드로 안내합니다.
  기본 테마는 모노톤 폴라로이드이며, 배경은 흰색, 불투명도 30%입니다.
  상단 팔레트 또는 설정 > 달력 배경색에서 전체 배경색을 변경합니다. 날짜별 색상과 따로 적용됩니다.
  설정에서 배경 불투명도를 0~100%로 조절할 수 있습니다.
  사진과 글자의 불투명도는 바뀌지 않습니다.
  어두운 바탕화면에는 다크 테마(밝은 글자), 밝은 바탕화면에는 라이트 테마를 사용하세요.
  설정 > 전체 글자 크기의 스피너 화살표로 8~48px를 1px씩 조절합니다(기본 13px).
  날짜, 요일, 월 제목, 메모, 설정 메뉴의 글자가 함께 비례해서 바뀝니다.
  큰 글씨가 창에 다 들어가지 않으면 달력 영역을 스크롤해서 볼 수 있습니다.
  글꼴에서 Windows에 설치된 글꼴을 선택하면 모든 글자에 함께 적용됩니다.
  달력 선 두께는 0~6px를 0.5px 단위로 선택합니다. 0은 선 없음입니다.
  공휴일은 Windows 국가/지역 설정으로 자동 선택하며, 국가를 직접 바꿀 수 있습니다.
  Nager.Date의 국가 공통 공휴일을 표시합니다. 주·도별 공휴일은 제외합니다.
  자료는 하루 단위로 갱신하며 오프라인이면 마지막으로 받은 자료를 사용합니다.
  공휴일 표시를 끄거나 공휴일 다시 불러오기로 재시도할 수 있습니다.
  시작 요일도 변경할 수 있습니다.
  Windows 시작 시 실행은 설정에서 켤 수 있습니다. 기본값은 꺼짐입니다.
  X 또는 최소화는 위젯을 트레이에 숨깁니다.
  작업표시줄 알림 영역의 달력 아이콘을 더블클릭하면 다시 나타납니다.
  트레이 우클릭 > 일반 창으로 가져오기로 바탕화면 고정을 풀 수 있습니다.
  완전히 종료하려면 트레이 우클릭 > 종료 또는 설정 > 앱 종료를 누르세요.

사진 틀과 자유 배치
  날짜 편집창에서 사진 틀 · 위치 · 기울기를 펼칩니다.
  편집할 사진을 선택하고 폴라로이드, 우표 또는 틀 없음을 고릅니다.
  폴라로이드와 우표는 Forge Seedream 5.0 Pro로 비공개 생성한 이미지 프레임입니다.
  미리보기에서 사진을 끌어 위치를 바꾸거나 가로·세로 위치 슬라이더를 조절합니다.
  기울기는 -30~30도입니다. 사진이 날짜 칸 밖으로 나가지 않도록 자동으로 맞춥니다.
  대는 칸을 채운 상태로 사진 중심을 옮기며, 기울기는 적용하지 않습니다.
  중은 기존 사진 영역 크기를 기준으로 배치합니다. 움직여도 메모 시작 위치와 폭은 변하지 않습니다.
  프레임 또는 배치를 설정한 소 사진은 32px입니다. 기본 위치는 오른쪽 위이고, 위치를 옮겨도 글자가 우선 표시됩니다.
  소는 첫 번째 사진을 표시합니다. 첫 번째 사진으로 버튼으로 대표 사진을 변경합니다.
  기본 위치 버튼으로 배치를 초기화하고, 테마의 기본 틀 따르기로 사진의 개별 틀 지정을 해제합니다.

테마 디자인과 저장
  설정 > 테마에서 기본 테마를 선택합니다. 폴라로이드는 모노톤 종이 달력, 아날로그는 모노톤의 밝은 선과 필기체 제목을 사용하는 반투명 달력입니다.
  종이·프레임·요일·강조색은 흰색·검정·회색이며 사진의 원래 색은 유지합니다. 원하는 배색은 새 테마 만들기에서 지정합니다.
  새 테마 만들기로 현재 디자인을 복사하고 이름, 색상, 종이 질감, 제목 스타일, 사진 틀, 모서리와 불투명도를 편집합니다.
  글꼴, 글자 크기와 선 두께도 테마에 저장할 수 있습니다.
  미리보기를 확인하고 저장하고 적용을 누릅니다. 취소하면 현재 달력은 바뀌지 않습니다.
  내 테마에서 다시 적용하거나 편집·복사·삭제할 수 있습니다. 최대 30개까지 보관합니다.
  테마와 사진별 프레임·배치는 자동 저장되며 전체 JSON 백업·복원에도 포함됩니다.

단축키
  Alt+왼쪽/오른쪽: 이전/다음 달
  Ctrl+T: 오늘
  Ctrl+,: 설정
  Esc: 사진, 설정, 편집창 닫기
  Ctrl+5: 커서가 있는 줄 취소선 켜기/끄기
  월 제목 클릭: 원하는 연월로 이동

데이터와 백업
  저장 위치: %APPDATA%\PhotoCalendar
  calendar.json: 날짜별 메모, 사진 연결, 설정
  photos: 자동 축소한 사진과 썸네일(기존 사진 파일은 유지)
  holiday-cache: 국가별 공휴일 캐시
  사진과 메모는 외부 서버로 전송되지 않습니다.
  설정 > 데이터의 백업 저장으로 사진을 포함한 JSON 파일을 내보낼 수 있습니다.
  백업 불러오기는 현재 기록을 별도 보관한 후 교체합니다.
  사진을 달력에서 제거해도 저장된 사진은 복구를 위해 데이터 폴더에 남습니다.
  손상된 기록은 직전 자동 백업에서 복구합니다. 원본도 별도로 보관합니다.

구글 캘린더 가져오기
  구글 캘린더 웹사이트 > 설정 > 가져오기 및 내보내기 > 내보내기에서 파일을 받습니다.
  설정 > 데이터 > 구글 캘린더 가져오기에서 .ics 또는 .zip 파일을 선택합니다. ZIP을 직접 풀 필요는 없습니다.
  가져올 시작일과 종료일을 지정합니다. 기본 기간은 올해 1월 1일부터 내년 12월 31일까지이며 과거 날짜도 지정할 수 있습니다.
  제목, 시간, 장소, 설명을 날짜별 메모로 가져옵니다. 종일 일정과 여러 날 일정도 지원합니다.
  반복 일정은 선택한 기간까지만 펼치며, 제외 날짜와 개별 일정의 변경·취소를 반영합니다.
  시간 일정은 Windows 시간대로 표시하고 종일 일정은 원래 날짜를 유지합니다. 종료일 자정은 다음 날 일정으로 추가하지 않습니다.
  미리보기에서 날짜와 내용을 확인한 뒤 적용하세요. 기간을 바꾸면 다시 미리보기를 해야 합니다.
  기존 메모에 추가하거나 해당 날짜의 메모를 교체할 수 있습니다. 기존 사진·날짜별 설정은 유지합니다.
  적용 직전에 before-calendar 파일로 기록을 자동 백업합니다. 같은 파일과 기간을 다시 추가하면 같은 메모를 반복해서 붙이지 않습니다.
  파일은 64MB 이하, ZIP 안의 캘린더는 100개 이하를 지원합니다. 큰 반복 일정은 기간을 나누어 가져와 주세요.
  기간 값으로 지정한 RDATE는 지원하지 않으며 오류로 안내합니다. 날짜·시간 값의 RDATE는 지원합니다.
  파일을 가져오는 기능이며 구글 계정 연결이나 자동 동기화는 아닙니다.

엑셀 가져오기·내보내기
  설정 > 데이터에서 엑셀 파일 선택으로 CalendarTask의 .xlsx 파일을 엽니다.
  날짜와 내용이 두 열로 있는 목록형, 월요일~일요일 칸이 있는 달력형을 지원합니다.
  미리보기로 날짜와 내용을 확인하고 같은 날짜 메모에 추가하거나 교체할 수 있습니다.
  달력형의 숫자 2026.1은 1월/10월이 모호하므로 실제 연월을 선택해야 합니다.
  적용 전 before-excel 파일로 기록을 자동 백업합니다. 다른 날짜와 기존 사진은 유지합니다.
  목록형/달력형 중 하나를 선택해 전체 기록을 엑셀로 내보냅니다.
  메모, 줄바꿈, 취소선, 글자색, 글자 크기, 날짜 배경색을 보존합니다.
  사진과 전체 설정은 엑셀에 포함되지 않습니다. JSON 백업으로 옮겨 주세요.
  엑셀은 한 칸에 32,767자까지 지원합니다. 더 긴 메모는 JSON 백업을 사용하세요.
  파일 가져오기·내보내기 방식이며 CalendarTask 계정 자동 동기화는 아닙니다.

개발
  Node.js 22.12 이상이 필요합니다.
  PowerShell: npm.cmd install
  개발 실행: npm.cmd run dev
  빌드: npm.cmd run build
  빌드 후 실행: npm.cmd start
  단위 테스트: npm.cmd test
  Windows 통합 테스트: npm.cmd run test:desktop
  실행 파일 만들기: npm.cmd run package

현재 범위
